# Инструкция администратора

## Первый запуск на тестовом ПК клиники

1. Войдите под индивидуальной Windows-учётной записью тестировщика.
2. Убедитесь, что компьютер защищён BitLocker и управляется системным администратором клиники.
3. Запустите `KlinVekt-Shcherbatova-Admin-Setup-2.5.11-x64.exe` и установите приложение.
4. Выберите локальную рабочую папку `C:\ClinicData\PulseClinic-Test` либо другой согласованный локальный каталог.
5. Убедитесь, что приложение сразу открыло рабочий экран: отдельного логина и пароля администратора больше нет.
6. Не используйте OneDrive, сетевой диск, UNC или SMB.

Приложение создаст папки «Входящие», «База», «Результаты», «Резервные копии» и «Журналы».

## Работа с данными

1. Скопируйте утверждённые выгрузки 1С в папку «Входящие».
2. Нажмите «Обработать новые выгрузки».
3. Проверьте журнал импорта и контрольные показатели.
4. При необходимости добавьте административные комментарии в разделе «Отчёт».
5. Используйте «Выгрузить PDF» и экспорт Excel для проверки результатов.
6. После завершения нажмите «Сохранить изменения» и создайте локальную резервную копию.

## Полная копия и восстановление

«Полная копия для переноса» создаёт `.ovbackup`, содержащий аналитику, техническую запись автора комментариев, историю импортов и сохранённые совместимые данные прежних версий. Локальные пути не переносятся.

Кнопка «Полная копия в JSON» создаёт переносимую JSON-копию тех же рабочих данных: аналитику, комментарии с историей, публикации, журналы импортов/экспортов, назначения заведующих и настройки доступа Viewer. Старые JSON по-прежнему открываются, но содержат только те данные, которые были записаны в них прежней версией приложения.

JSON содержит персональные данные и действующие PIN врачей Viewer. Храните его только в защищённой папке клиники. Для штатного аварийного восстановления всей SQLite-базы предпочтительна копия `.ovbackup`.

Для проверки восстановления:

1. Создайте `.ovbackup`.
2. Выполните ещё одно безопасное изменение.
3. Нажмите «Восстановить полную копию» и выберите созданный файл.
4. После перезагрузки приложения рабочий экран откроется без логина и пароля.
5. Сверьте итоговые показатели.

## Перенос на сервер

1. Создайте финальную `.ovbackup` на тестовом ПК.
2. Зафиксируйте SHA-256 файла.
3. Перенесите его через защищённый ресурс клиники или зашифрованный носитель.
4. Установите версию 2.5.11 на сервере под выделенной RDP-учёткой.
5. Выберите локальную серверную папку `C:\ClinicData\PulseClinic`.
6. Запустите чистую установку: рабочий экран откроется автоматически.
7. Восстановите перенесённую `.ovbackup`.
8. Сверьте число месяцев, врачей, импортов и контрольные метрики.
9. Создайте две серверные резервные копии.

SHA-256 показывается после создания `.ovbackup`. Для независимой повторной проверки выполните:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "C:\путь\к\копии.ovbackup"
```

Только после проверки серверных копий системный администратор удаляет с тестового ПК исходные выгрузки, рабочую папку и промежуточные копии согласно правилам клиники.

## Ограничения

- Администраторская программа предназначена только для администратора; врачи входят в отдельный Viewer.
- Администраторскую программу и SQLite нельзя расшаривать врачам.
- Рабочие каталоги нельзя размещать в OneDrive или SMB/UNC.
- Установщик сохраняется только в защищённом программном архиве; файлы с персональными данными рядом с ним хранить нельзя.

## Отчёты для врачей без серверной службы

1. В настройках администратора включите работников и проверьте их постоянные PIN. Задайте администраторский PIN Viewer: он нужен и для ZIP установленного Viewer, и для полного входа администратора в автономный HTML.
2. В блоке «Заведующие отделениями» выберите заведующего. Настройка сохраняется в администраторской базе, а его доступ к Viewer включается автоматически.
3. PIN врача состоит из четырёх цифр и сохраняется между всеми месяцами. Заведующий входит с тем же личным PIN, отдельный пароль роли не требуется.
4. На странице «Отчёт» нажмите «Файл для Viewer», выберите периоды и получателей. Личный отчёт, специализации и отделения отмечены по умолчанию; для выбранного заведующего врачи его отделения добавятся автоматически.
5. Для прямой передачи подтвердите администраторский PIN и нажмите «Один автономный HTML». В файле появится отдельный вход администратора со всеми включёнными врачами, периодами, отделениями и специализациями. Заведующий выбирает врача своего отделения, всё отделение или конкретную специализацию; обычный врач видит только себя. В личном отчёте работают переключатели окон назначений и клиентской базы 12/24/36 месяцев. Период выгрузки пациентских данных указан явно, реестр пациентов сворачивается, рейтинги площадок доступны только для чтения.
6. Для общей папки нажмите «ZIP для установленного Viewer», установите `KlinVekt-Shcherbatova-Viewer-Setup-2.5.11-x64.exe`, затем импортируйте ZIP в панели «Администратор» Viewer.
7. Windows-учётки и таблица NTFS для входа не используются; каждый набор страниц зашифрован PIN конкретного получателя.

Viewer работает только во время открытого окна. SQL-сервер, веб-сервер и фоновая служба не требуются. В общей папке нет рабочей SQLite и исходных выгрузок 1С.

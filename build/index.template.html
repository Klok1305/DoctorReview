Загрузка отчётов из 1С
Загружайте сюда выгрузки из 1С (.xls / .xlsx) — можно пачкой, папкой или ZIP-архивом, сразу за несколько месяцев. Поддерживаются отчёты: выработка и возвращаемость пациентов и КБ (по врачу), возвращаемость первички, простой сотрудников, собственная запись в 1С (общие). Тип отчёта, врач и период определяются автоматически по содержимому — имена файлов не важны.

Публикация для врачей

Один HTML можно сразу передать и открыть без установки. ZIP предназначен для импорта в установленный Viewer и общую папку.

Периоды

В новый файл войдут только отмеченные месяцы. При импорте ZIP ранее загруженные месяцы для тех же врачей сохранятся.

Заведующие отделениями

Полная публикация: Будут выбраны все доступные периоды и все виды страниц.

Список ниже — для ручной выгрузки: в нём только врачи с включённым доступом Viewer. Кнопка полной публикации включает и остальных врачей с отчётами, не меняя настройки доступа.

Заведующие: в режиме «Только выбранные врачи» заведующий получит свою личную страницу и выбранные сводные своего отделения и специализации. Второй режим дополнительно включит личные и сводные страницы всех врачей управляемых отделений.
Вход администратора в HTML: подтвердите действующий администраторский PIN Viewer. Он зашифрует отдельный полный каталог всех отчётов, включённых в файл, и не будет сохранён открытым текстом.
